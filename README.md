# PhoneBook Application

## Описание
Программа для управления телефонной книгой, которая предоставляет функции поиска, добавления, редактирования и удаления контактов. Телефонная книга хранится в базе данных SQLite.

## Основные возможности
- Создание таблицы `PhoneBook` (если она не существует):
  - `name` (имя)
  - `number` (номер телефона)
  - `notes` (заметки)
- Подсчет общего количества записей в телефонной книге.
- Быстрый поиск контактов по имени.
- Вывод всех контактов с сортировкой по имени.
- Добавление нового контакта с именем, номером и заметками.
- Изменение номера телефона или заметок для существующего контакта.
- Удаление контакта по имени и номеру телефона.

## Требования
- Python 3.7+
- Библиотеки:
  - `sqlite3`
  - `sqlalchemy`

## Установка
1. Клонируйте репозиторий или скопируйте код в свой проект.
2. Убедитесь, что у вас установлен Python 3.7 или выше.
3. Установите необходимые библиотеки, если они еще не установлены:
   ```bash
   pip install sqlalchemy
   ```

## Использование
1. Запустите скрипт:
   ```bash
   python phonebook.py
   ```
2. Следуйте инструкциям в консоли для выполнения различных операций с телефонной книгой.

## Пример работы
1. Программа покажет количество записей в базе данных.
2. Возможные действия:
   - **Быстрый поиск:** Введите `Y` и имя для поиска.
   - **Вывод всех записей:** Автоматически отображается после быстрого поиска или по запросу.
   - **Добавление контакта:** Введите `Y` для добавления нового контакта.
   - **Редактирование:** Введите `Y` для изменения номера или заметок.
   - **Удаление контакта:** Введите `Y` для удаления контакта.
   - **Повторение поиска:** Выберите `Y` для нового поиска или `N` для выхода.

## Примечания
- Программа автоматически создаст базу данных `PhoneBook.db` и таблицу `PhoneBook`, если они не существуют.
- Все изменения сохраняются автоматически с использованием метода `commit()` SQLite.
- Для выхода из программы выберите `N`, когда будет предложено повторить поиск.
